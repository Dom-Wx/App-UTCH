# UTCH ParkMate

Aplicación móvil/web para el control de acceso y consulta de disponibilidad de estacionamientos en tiempo real en la **Universidad Tecnológica de Chihuahua (UTCH)**.

## Cómo iniciar el proyecto

```bash
cd "app UTCH"
npx expo start --web
```

Para abrir el menú interactivo de Expo (Android / iOS / Expo Go):

```bash
cd "app UTCH"
npx expo start
```
Quien lo descargue debe correr npm install para regenerar node_modules.
